История возникновения датасета занятная и цель актуальная. </br>
▶️ Контекст от автора **zackthoutt**:</br>
🍇 Посмотрев Somm (документальный фильм о мастерах-сомелье), я задался вопросом, как я могу создать предиктивную модель для определения вин с помощью слепой дегустации, как это сделал бы мастер-сомелье. Первым шагом в этом путешествии был сбор некоторых данных для обучения модели. Я планирую использовать глубокое обучение для предсказания сорта вина с использованием слов в описании/обзоре. Модель по-прежнему не сможет дегустировать вино, но теоретически она может определить вино на основе описания, которое может дать сомелье. </br></br>

❔ Это, конечно, не совсем под дашборд. </br></br>
🍇Однако тема такая красивая. И некоторые данные дашбордовского характера удалось извлечь. Мне кажется интересным показатель point - количество баллов, которое **WineEnthusiast** оценил по шкале от 1 до 100. А массовое производство всё равно лежит в пределах первого диапазона максимальной цены. </br></br>
